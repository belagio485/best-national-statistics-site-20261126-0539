NusaAngka — Indonesia in Numbers: an original national statistics site for Indonesia with sourced population, economy, regions, wellbeing and environment pages, hand-drawn SVG charts, a searchable 38-province table, a province comparator and CSV downloads. It runs entirely from its own static files, on desktop and phone, with no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080/
```
